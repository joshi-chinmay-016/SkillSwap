# System Architecture

SkillSwap Arena is engineered as a decoupled, multi-tier platform separating client presentation, edge proxying, domain service orchestration, asynchronous state coordination, vector knowledge indexing, and relational persistence.

![SkillSwap Arena System Architecture](../diagrams/system-architecture.svg)

---

## 1. High-Level Architecture Overview

The system is organized into four core layers:

```
[ Client Presentation Tier ]  -->  React 18 SPA (Vite, TailwindCSS, Zustand)
            │
            ▼
[ Edge & Ingress Proxy ]     -->  Nginx (WSS Upgrade, Security Headers, Rate Limits)
            │
            ▼
[ Application Core Tier ]    -->  FastAPI (Router → Service → Repository Pattern)
            │
    ┌───────┴───────────────────────────────┐
    ▼                                       ▼
[ Persistence & State ]           [ Vector & External AI ]
• PostgreSQL 16 (Relational DB)    • FAISS CPU Vector Index (3072d)
• Redis 7.0+ (Pub/Sub & Presence)  • Google Gemini LLM / Embeddings API
• GCP Secret Manager               • Jitsi Meet Video Infrastructure
```

## 2. Layer Responsibilities

### 2.1 Client Presentation Tier
* **Technology**: React 18 SPA built with Vite and TailwindCSS.
* **Responsibilities**:
  - Delivers both the **Student Portal** (Peer Learning, Skill Verification, Roadmaps, AI Mentor, Video Workspace) and the **Platform Admin Console** (`/admin/*`).
  - Manages client-side authentication tokens in Zustand memory with Axios interceptors.
  - Maintains active bidirectional WebSocket connections to `/ws/{user_id}` for instant workspace synchronization and system notifications.
  - Embeds Jitsi Meet IFrames with authoritative meeting URLs generated by the backend.

### 2.2 Edge & Ingress Proxy (Nginx)
* **Technology**: Nginx 1.25 Alpine Linux.
* **Responsibilities**:
  - Terminates TLS/HTTPS traffic and enforces strict HTTP security headers (`X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`).
  - Proxies `/ws/*` requests with connection upgrade headers (`Upgrade $http_upgrade`, `Connection "Upgrade"`).
  - Enforces client body size constraints (25MB limit) and API rate limiting zones.
  - Emits structured JSON access logs with client IP, request time, status, and `X-Request-ID`.

### 2.3 Application Core Tier (FastAPI)
* **Technology**: Python 3.12, FastAPI 0.115+, SQLAlchemy 2.0.
* **Responsibilities**:
  - Implements a strict **Router → Service → Repository** architectural pattern.
  - Handles authentication, OAuth2 linking, role authorization (`require_admin`), and active user checks.
  - Coordinates peer session booking with coin escrow idempotency.
  - Executes grounded AI session intelligence synthesis and RAG document querying.
  - Exposes low-cardinality Prometheus operational metrics on `/metrics`.

### 2.4 Persistence, Caching & Coordination
* **PostgreSQL 16**: 37 relational tables managed by Alembic migrations (`m10a1_phase8_rbac_and_admin`). Stores users, credentials, capabilities, sessions, feedback, coin transactions, and immutable admin audit logs.
* **Redis 7.0+**: In-memory data store for multi-worker WebSocket Pub/Sub coordination, participant presence heartbeats (60s TTL), and distributed token bucket rate limiting.
* **FAISS Vector Store**: 3072-dimensional vector indexing engine storing parsed document chunks with 150-character overlap halos for the AI Mentor.

## 3. Communication Protocols

| Channel | Protocol | Use Case | Security Controls |
| :--- | :--- | :--- | :--- |
| **Client ↔ API** | HTTPS / REST | Account management, catalog queries, booking, analytics | Bearer JWT Header (`Authorization: Bearer <token>`) |
| **Client ↔ WebSocket** | WSS (WebSockets) | Live presence, real-time notes sync, notifications | Query/Bearer JWT Token Validation on Connect |
| **Client ↔ Video** | WebRTC / HTTPS | Peer audio and video collaboration via Jitsi | Authoritative generated meeting link and room scoping |
| **Backend ↔ Redis** | RESP3 (TCP) | Pub/Sub message broadcasts, presence key TTLs | Authenticated VPC private network peering |
| **Backend ↔ DB** | PostgreSQL Wire (TCP) | ACID relational transactions and audit records | Managed connection pool, SSL enforced in production |
| **Scraper ↔ Metrics** | HTTP (Internal) | Prometheus scraping of platform telemetry | Internal network binding / VPC restriction |
